A program that writes one image summing up the world's news of Thursday 19 November 2026. The image is drawn programmatically (`generate_image.py`, Python + PIL) so every word is crisp, and `main.py` copies it to the output directory.

What's in the image:

1. Trump, Xi and Putin meet in Shenzhen (APEC summit)
2. The US and Iran exchange fire
3. The Crimean Bridge is hit again — third attack this week
4. Anthropic's $1.4tn debut, the biggest IPO of all time
5. Myanmar's genocide verdict at the UN court
6. Voyager 1 reaches one light-day, 50 years after launch

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
